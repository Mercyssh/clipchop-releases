# ClipChop releases

Installers for **ClipChop**, no fuss video editing that just makes sense.

Download the latest version from the [Releases page](https://github.com/Mercyssh/clipchop-releases/releases/latest).

| Platform | Files |
|---|---|
| Windows | `.exe` installer (recommended) or `.msi` |
| macOS | `.dmg` (first launch: right-click the app and choose Open) |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On Windows 10, install [Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) first.

This repository only hosts release files. To report a bug or share feedback, use the feedback page on the ClipChop website.
